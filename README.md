# Sally Made Africa — TravelConnect

Application mobile Flutter de voyage orientee Afrique. Nom de code : TravelConnect.

## Ce que fait l'application

- Parcours voyageur : decouverte de destinations, preparation de voyage.
- **eSIM integree** : popup d'installation, recharge (top-up) et notifications
  en direct, pour arriver connecte sans chercher une carte SIM locale.

## Structure

- `lib/` : code Dart de l'application Flutter.
- `esim-integration/` : travail d'integration eSIM.
- `TravelConnect Redesign/` : specifications de design (maquettes HTML,
  captures, styles) issues de la refonte visuelle.

## Lancer

```
flutter pub get
flutter run
```

## Etat d'avancement

- Base Flutter fonctionnelle, integration eSIM fusionnee sur la branche
  principale (popup d'installation, top-up, notifications live).
- Refonte visuelle : specifications produites, implementation non terminee.
- Pas encore de publication sur les stores ni de backend de production.
