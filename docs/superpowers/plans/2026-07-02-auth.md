# Plan — Auth Sub-Project (TDD)

Spec: `docs/superpowers/specs/2026-07-02-auth-design.md`
Branch: `auth` (merge `--no-ff` into `main` at the end).
Note: no Flutter SDK in this session's sandbox — tests are written with each task, the whole suite is executed on Léo's machine before merge (`flutter pub get && flutter gen-l10n && flutter analyze && flutter test`).

Each task = write test(s) + implementation + granular commit. Ledger: `.superpowers/sdd/progress.md`.

## Task 1 — AuthUser entity + AuthFailure
- `lib/features/auth/domain/auth_user.dart`: immutable `AuthUser(id, email?, phone?, displayName?)`, equality on `id`.
- `lib/core/error/failure.dart`: add `AuthFailure`.
- Tests: `test/features/auth/domain/auth_user_test.dart` (equality, hashCode), failure subtype check.

## Task 2 — AuthRepository interface + FakeAuthRepository test helper
- `lib/features/auth/domain/auth_repository.dart` per spec (all methods `Result`-returning, `authStateChanges()` stream, `currentUser`).
- `test/helpers/fake_auth_repository.dart`: scriptable results, `StreamController<AuthUser?>` exposed for tests.
- Test: fake behaves as scripted (sanity test locks the contract).

## Task 3 — Guest mode provider (persisted, race-safe)
- `lib/features/auth/presentation/auth_providers.dart`: `guestModeProvider` (`Notifier<bool>`), persisted `guest_mode` in shared_preferences, `loaded` guard so an early toggle isn't overwritten (fixes pattern-debt from Foundation #2).
- Tests with `SharedPreferences.setMockInitialValues`.

## Task 4 — AppAuthState + combined provider
- `lib/features/auth/presentation/auth_providers.dart`: sealed `AppAuthState` (`Authenticated`/`Guest`/`Unauthenticated`), `authRepositoryProvider`, `authStateProvider` (stream), `appAuthStateProvider` combining stream + guest flag (signed-in wins).
- Tests: combination matrix using FakeAuthRepository (override `authRepositoryProvider`).

## Task 5 — SupabaseAuthRepository + failure mapping + secure storage
- `lib/features/auth/data/supabase_auth_repository.dart`: adapter over `supabase.auth`; private `_guard<T>()` mapping `AuthException`→`AuthFailure`, socket/timeouts→`NetworkFailure`, else `UnknownFailure`.
- `lib/features/auth/data/secure_auth_storage.dart`: `LocalStorage` impl over `flutter_secure_storage`.
- `lib/core/config/supabase_client.dart`: pass `authOptions: FlutterAuthClientOptions(localStorage: SecureAuthStorage())`.
- `pubspec.yaml`: add `flutter_secure_storage`.
- Tests: failure-mapping unit tests (exception→Failure), user-mapping (supabase `User`→`AuthUser`).

## Task 6 — AuthController (actions)
- `lib/features/auth/presentation/auth_controller.dart`: `AsyncNotifier<void>`; methods `signInWithEmail`, `signUpWithEmail`, `sendOtp`, `verifyOtp`, `signInWithGoogle`, `signInWithApple`, `continueAsGuest` (sets guest flag), `signOut` (clears guest flag). Exposes `AsyncValue` for loading/error.
- Tests: each action against FakeAuthRepository (success + failure paths, guest flag side-effects).

## Task 7 — l10n strings for auth
- Add keys to `lib/core/l10n/app_en.arb`: signIn, signUp, email, password, confirmPassword, phoneNumber, otpCode, continueAsGuest, signInWithGoogle, signInWithApple, signInWithPhone, signOut, sendCode, resendCode, verify, checkYourEmail, invalidEmail, passwordTooShort (≥8), passwordsDontMatch, invalidPhone, authErrorGeneric, noAccountYet, alreadyHaveAccount.
- `flutter gen-l10n` run by Léo; keys referenced via `AppLocalizations`.

## Task 8 — LoginScreen + SignUpScreen
- `/login`: form validation (email regex, password ≥8), buttons per spec, guest button calls controller, SnackBar on error, buttons disabled while loading.
- `/signup`: email/password/confirm validation; success → info or auto-signed-in.
- Widget tests: validation errors shown, guest tap flips guest state, submit calls controller (fake repo).

## Task 9 — PhoneLoginScreen
- Two-step (phone → OTP), resend, validation (basic E.164 check).
- Widget test: step transition after sendOtp success.

## Task 10 — Router guard + routes + refresh
- Add `/login`, `/signup`, `/phone-login` top-level routes.
- `refreshListenable` bridge on `appAuthStateProvider`; redirect per spec matrix; `const guardedForGuests = ['/profile']`.
- ProfileScreen: Sign out button.
- Tests: redirect matrix (unauth→/login, guest→/home ok, guest→/profile→/login, authed on /login→/home). Update existing boot test if it assumed no redirect.

## Task 11 — Final review + docs + handoff
- Whole-branch review, update `.superpowers/sdd/progress.md`, HANDOFF.md (state → Auth done, next Catalog), verify suite green on Léo's machine, merge `--no-ff`.
